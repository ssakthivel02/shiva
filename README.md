## Next-generation direction

Shiva now evolves independently beyond the donor experience. Current enhancement work focuses on a distinctive Shiva visual language, cinematic discovery, Tamil-first presentation, source-aware knowledge pathways, strong provenance cues, bounded AI/reflection, responsive interaction and accessibility.

The **Trinetra experience** expresses three deliberate lenses throughout the product:

1. **Source / ஆதாரம்** — evidence, provenance and record boundaries.
2. **Context / சூழல்** — related traditions and learning pathways without collapsing distinct sources.
3. **Reflection / சிந்தனை** — clearly labelled interpretation or generated guidance that never replaces source evidence.

## Release discipline

Enhancements are developed on controlled branches and are not promoted merely because they build successfully. TypeScript/build validation, responsive behavior, accessibility, route/PWA integrity, evidence labels and production deployment must remain green before release.
